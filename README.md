# Rouzbeh Store — static GitHub Pages export

This self-contained snapshot was recovered from the repository's published source commit. It is prepared for `https://roozbe2day.github.io/rouzbeh-store/`.

- HTML files: 126 (including the custom 404 page)
- Package files: 1067 total, including 522 image files. The ZIP contains this complete directory tree and local WordPress theme/upload assets.
- Persian and English page trees and WordPress theme/plugin assets are included.
- Internal first-party URLs use the GitHub Pages project path. The deleted legacy promotional popup is removed. The desktop product-category menu opens and closes locally, with a viewport-bounded scrollable panel. Homepage promo artwork is stored locally. The English homepage uses the current English banner artwork, with the complete image visible in each frame and the three hero slides loaded eagerly.

This is a static snapshot. Product browsing pages and local images render without the live WordPress site. Checkout, account authentication, cart updates, live search, comments, and form submissions require a server and remain linked to the live store where applicable.

GitHub Pages should deploy from the `main` branch root. `.nojekyll` is included.
